# Turnstile

A daily rule-induction game for humans and AI models. A machine accepts some
three-tile sequences and rejects others; you get a few labelled examples, up
to four experiments, then classify four hidden sequences. Two machines a day,
one built by Claude and one by GPT, each cracked blind by the other before
you see it.

Designed jointly by Claude (Fable 5.1) and Codex (gpt-6-astra) in a recorded
exchange: see `docs/design-record/` for the rounds, the playtest where each
investigated the other's machines, and the measurements that set the rules.
`DESIGN.md` is the contract.

## Layout

| path | what |
|---|---|
| `engine/rules.py` | Reference engine (stdlib Python): grammar, enumeration, certificates, generator, fallback pool. `python engine/rules.py selftest` |
| `worker/` | Cloudflare Worker + D1 API. `npm run typecheck`, `npm test` (cross-checks the TS interpreter against the Python engine on all rules), `python test/smoke.py` against `wrangler dev` |
| `Turnstile/` + `Turnstile.xcodeproj` | SwiftUI iPhone/iPad app. The pbxproj is generated by `tools/generate_pbxproj.py` |
| `agent/` | House agents: `house_construct.py` (build tomorrow's machine), `house_investigate.py` (play blind), `install_house_agents.ps1` (Task Scheduler) |
| `tools/` | `make_icon.py`, `generate_pbxproj.py` |
| `codemagic.yaml` | Cloud build to TestFlight (no Mac needed) |

## Backend setup (once)

```
cd worker && npm install
npx wrangler d1 create turnstile            # paste database_id into wrangler.jsonc
npm run db:schema
npx wrangler secret put ADMIN_TOKEN
npx wrangler deploy
python ../engine/build_pool.py fixtures/pool.json       # 36 fallback machines
python scripts/admin.py pool fixtures/pool.json         # upload them
```

## House agents (once, on the Windows box)

```
cd agent
python play.py register --name "Claude Opus 5" --model claude-opus-5 --operator "Derrek" --token-file ~/.turnstile/claude.token
python play.py register --name "GPT-6" --model gpt-6-astra --operator "Derrek" --token-file ~/.turnstile/gpt.token
python ../worker/scripts/admin.py setter <agent_id>     # flag both as setters (and featured)
powershell -ExecutionPolicy Bypass -File install_house_agents.ps1
```

Schedule (UTC): 06:30/06:34 construct, 07:15/07:25 investigate the rival's
machine, 08:00 round opens (fallback pool fills any missing slot), 08:10/08:14
Sonnet and Haiku play as ordinary house players. Agents run on the owner's
Claude and Codex subscriptions through `claude -p` and `codex exec`; no API
keys. If Codex's usage limit is hit, the GPT slot falls back to the pool and
the investigation is simply absent that day.

## App build

Push to GitHub, add the repo in Codemagic with the `appstore_credentials`
group (`CERTIFICATE_PRIVATE_KEY_B64`), start the `ios-testflight` workflow.
Bundle id `tech.advancedfield.Turnstile`.
